# Проект: Интерактивная карта здоровья города

**Категория:** Здравоохранение

## 💊 Суть проекта

Интерактивная карта, наполняемая пользователями, с оценками объектов городской инфраструктуры по специальным наборам критериев. Цель — визуализировать «здоровье» муниципалитетов и дать жителям инструмент для выбора лучших мест, а городским службам — данные для улучшения среды.

Проект разрабатывался в рамках **хакатона** (укажите название, если нужно) за ограниченное время. Команда успешно реализовала прототип, который позволяет пользователям оставлять оценки и просматривать агрегированные данные на карте.

## 🧑‍💻 Мой вклад в проект

В составе команды я отвечала за **бэкенд-часть**:
- Разработка REST API для взаимодействия с фронтендом (обработка запросов, валидация, маршруты).
- Нормализация и структурирование данных для загрузки в PostgreSQL (парсинг, очистка, приведение к единому формату).
- Интеграция с базой данных: создание схем, миграции, оптимизация запросов.
- Настройка эндпоинтов для получения данных о объектах и их рейтингах.

## Технический стек

- **Бэкенд:** Python (использовались FastAPI / Django — укажите свой фреймворк, если хотите)
- **Фронтенд:** Next.js
- **База данных:** PostgreSQL
- **Хостинг:** Yandex Cloud
