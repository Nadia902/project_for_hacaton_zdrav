# Проект: Интерактивная карта здоровья города

**Категория:** Здравоохранение

## 💊 Суть проекта

Интерактивная карта, наполняемая пользователями, с оценками объектов городской инфраструктуры по специальным наборам критериев. Цель — визуализировать «здоровье» мунципалитетов и дать жителям инструмент для выбора лучших мест, а городским службам — данные для улучшения среды.

## Технический стек

- **Бэкенд:** Python
- **Фронтенд:** Next.js
- **База данных:** PostgreSQL
- **Хостинг:** Yandex Cloud
